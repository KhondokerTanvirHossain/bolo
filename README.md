# Bolo

A voice-first English speaking buddy for Bangla speakers who know English on paper but freeze when they speak. You talk with Bolo for 5 minutes, then a Coach gives you 3 things to try.

**Build order (decided 7 Nov 2026):** desktop browser (closed beta) → mobile browser → Android app.
