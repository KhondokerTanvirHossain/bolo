# P1h Dialogs: Focus, Esc and the Page Behind

**Goal:** Every sheet keeps keyboard focus inside itself, Esc takes the safe way out, and focus returns to what opened it (design system 5-desktop-and-web; design audit P1-8). Home behind a sheet can't be reached.

**Scope:**
- the free-limit sheet (Esc = Wait);
- the sign-in sheet (Esc = Not now);
- Delete everything (Esc = Keep my data);
- Delete recording (Esc = Keep it);
- Save progress (Esc = Not now, then back);
- the talk's end sheet already had Esc.

**Also:**
- Home is `inert` while a sheet is open;
- the week strip reads its states through visually hidden text (`.bo-sr`), not `aria-label` on list items (P1f review minor).

**Built:**
- `web/src/ui/useDialog.ts` (focus in, Tab trap, Esc, focus restore; capture phase so page key handlers don't also act);
- `web/src/ui/DialogCard.tsx`.
