# ScreenMemoryEmpty

What Bolo remembers before the first talk after release, after "Forget everything", or with remembering off.

- **One quiet card:** "Nothing yet", followed by "After your next talk, the things Bolo will ask you about show up here."
- **The switch stays visible,** so the learner can turn remembering off before Bolo notes anything.
- **With the switch off,** the card instead reads "Bolo isn't keeping notes. Each talk starts fresh."
