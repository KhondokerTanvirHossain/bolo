# DesktopTalk

The talk fills the window: no sidebar, captions at the top centre at 760px reading width, and the controls in a floating dock with their keys written underneath: Space (done), P (pause), R (repeat), Esc (end). Switching tabs pauses the talk and closes the mic.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "talk").
