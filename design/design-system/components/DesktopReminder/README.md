# DesktopReminder

After the first talk: four time slots, a preview of the exact notification, and a "Keep it private" switch that shortens it to "Time for today's talk". "Turn on reminders" opens the browser's own permission box; **Add to my calendar instead** downloads a daily calendar event as a quiet alternative. *Changed 2026-11-14: "Remind me on my phone" (a code to scan) moves to P1.* Never ask for permission when the page opens.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "reminder").
