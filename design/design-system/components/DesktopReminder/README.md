# DesktopReminder

After the first talk: four time slots, a preview of the exact notification, and a "Keep it private" switch that shortens it to "Time for today's talk". "Turn on reminders" opens the browser's own permission box; the calendar and the phone are quiet alternatives. Never ask for permission when the page opens.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "reminder").
