# ScreenSettings

Me → Settings (SET-1 to SET-4, US-9.2, US-9.4, US-9.5), built from SettingsRow. Exactly two groups.

- **Speaking:** **Bolo's voice** (Female or Male; British, American or Indian; opens ScreenVoicePicker; added 2026-11-13), **Bolo's mood** (Friendly, Funny, Professional, Calm; opens ScreenMoodPicker; added 2026-11-13), Bolo's speed (Slower / Normal), **Talk view** (Chat, the default: the live chat with your words, time left in numbers and a level meter; or Classic: Bolo's caption only and the time arc; added 2026-11-12), Captions (in Chat view it shows or hides the whole chat), **Time to answer** (AX-7, changed 2026-11-14: Automatic, Quick, Normal or Relaxed; opens ScreenAnswerTime; the row shows "Automatic · Relaxed" or the chosen speed), **I stammer** (AX-8: Bolo waits through repeats and blocks without prompting — silence help never before 16 s, a turn never ends before 4.5 s of silence — and the feedback never names repeats or long pauses as something to fix), Ambient sound.
- **Display & data:** Scene and companion (opens ScreenScenePicker), Voice-only mode, Theme (System / Day / Night, P1), Data saver (P1), Bangla helper text (on by default, ONB-6).
- Every change applies at once; there is no Save button. Text size always follows the phone's font setting, so there is no text-size control here.
