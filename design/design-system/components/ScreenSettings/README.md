# ScreenSettings

Me → Settings (SET-1 to SET-4, US-9.2, US-9.4, US-9.5), built from SettingsRow. Exactly two groups.

- **Speaking:** **Bolo's voice** (Female or Male; British, American or Indian; opens ScreenVoicePicker; added 2026-11-13), **Bolo's mood** (Friendly, Funny, Professional, Calm; opens ScreenMoodPicker; added 2026-11-13), Bolo's speed (Slower / Normal), **Talk view** (Chat, the default: the live chat with your words, time left in numbers and a level meter; or Classic: Bolo's caption only and the time arc; added 2026-11-12), Captions (in Chat view it shows or hides the whole chat), **More time to answer** (AX-7: Bolo's silence prompts come at 16, 30 and 90 s instead of 8, 15 and 45 s), **I stammer** (AX-8: Bolo waits through repeats and blocks without prompting, the turn doesn't end early, and the feedback never names repeats or long pauses as habits), Ambient sound.
- **Display & data:** Scene and companion (opens ScreenScenePicker), Voice-only mode, Theme (System / Day / Night, P1), Data saver (P1), Bangla helper text (on by default, ONB-6).
- Every change applies at once; there is no Save button. Text size always follows the phone's font setting, so there is no text-size control here.
