# DesktopFeedback

Strength, three fixes and skills sit in a list on the left; the chosen card opens on the right with your clip and the model clip side by side. ↑↓ moves through the list, T tries the fix. Nothing needs a swipe.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "debrief").
