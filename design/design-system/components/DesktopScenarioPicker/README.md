# DesktopScenarioPicker

"Change" under the Talk button on desktop (SCN-1, US-7.1). *New in v44, 2026-11-14.* The same choice as ScreenScenarioPicker in a centred 480 px dialog over Home, like ScreenRating on desktop.

- Free talk or Standup rehearsal as radio cards; picking Standup shows Friendly / Realistic inside its card.
- ↑↓ moves between the cards, ←→ between Friendly and Realistic, Enter applies, Esc closes without changing.
- One choice applies and closes; the line under the Talk button then reads "Standup rehearsal · Realistic · 5 min · Change".
- Canvas: 1440 × 900 (the preview scales it down to fit). Classes: `dk-*` and `bo-*` in `bundle.css`.
