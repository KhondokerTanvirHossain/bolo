# DesktopProgress

Voice comparison and effort side by side, four skill trends in one row, patterns and history next to each other. The grid drops to 2 columns from 1024 to 1279px.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "progress").
