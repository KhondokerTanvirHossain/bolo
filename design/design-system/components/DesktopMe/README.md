# DesktopMe

A section list on the left, settings on the right. A desktop group adds the microphone, how a turn ends, pause on tab switch, and keyboard shortcuts.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "me").
