# StandupTip

The scenario fix in a Standup rehearsal's debrief (ASM-4, US-7.3). *New in v44, 2026-11-14.* It takes the place of the lowest-ranked fix, so a debrief still has at most 3 cards; it never pushes out the sound fix.

**Needs:** the tip's title (one of a short fixed list), one sentence the learner really said, the better version, a model clip of the better version, a one-line why, and handlers for `tryIt` and `dispute`; the position (2 of 3).

**The tips (P0):**
- **Lead with the outcome** — say what's done first, then the detail.
- **Give a date, not "soon"** — an ETA with a day or time.
- **Say the blocker and what you need** — name it and ask for the help.

**Use**
- It is a FixCard: eyebrow "Standup tip" (`hills-ink`), title in `title-2`, You said → Try → tip row → Try it.
- You said is plain text (no clip needed); the change in Try is marked with `bo-better`.
- Try it records the better version, as in Say it better drills. "That's not what I said" removes it, as on every fix.

**Don't:** grade the whole update, show more than one tip, or use it in Free talk.
