# DesktopPlans

All plans side by side with the price as the biggest number. On a computer bKash shows a QR code to scan with the bKash app; card payment is the other choice. Cancelling still takes two clicks.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "plans").
