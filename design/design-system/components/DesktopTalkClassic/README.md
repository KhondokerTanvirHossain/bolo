# DesktopTalkClassic

The talk as it was before the chat (Settings → Talk view → Classic). Only Bolo's current line shows as a caption, the learner's words aren't shown, and time left is the arc around the mic with no numbers.

- Everything else is as in DesktopTalk: full window, the floating dock, keys Space, P, R and Esc, and the talk pauses on tab switch.
- For learners who'd rather focus on speaking than reading (the original TLK-8 and TLK-16).
