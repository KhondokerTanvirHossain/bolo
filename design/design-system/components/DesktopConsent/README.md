# DesktopConsent

Every onboarding step is a centred card (480px, or 600px wide) over the blurred dusk, with a step count. The two consent answers are equal and side by side. The browser asks for the microphone right after this card explains why.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "consent").
