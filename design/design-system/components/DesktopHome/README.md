# DesktopHome

The phone's bottom tabs become a sidebar with the same three tabs, the free-talk counter and a code to open Bolo on the phone. The scene is a wide hero with the Talk button inside it. Content never stretches past 1120px.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "home").
