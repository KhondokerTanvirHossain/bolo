# DesktopMicPicker

Desktop only. Computers have several microphones (laptop, headset, webcam), so the mic check lists them, shows a live level and remembers the choice. One kind line suggests headphones: laptop speakers feed Bolo's voice back into the mic.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "mic").
