# DesktopMeetBolo

The first screen on a computer. Browsers block sound until the user clicks, so desktop opens on one calm screen with the logo and a single "Meet Bolo" button; that click unlocks audio and starts the voice welcome. The logo face appears here and in the splash only.

- Canvas: 1440 × 900 (the preview scales it down to fit). Layout rules, breakpoints and the keyboard map are in *Desktop and web*.
- Classes: `dk-*` in `bundle.css` (section "Desktop and web"), built on the same `bo-*` components and tokens as the phone.
- Clickable version: the Desktop prototype card (screen "start").
