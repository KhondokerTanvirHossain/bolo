# ScreenRating

"How was today?" (DBF-8, US-4.11; v39, 2026-11-13). A bottom sheet over the feedback summary when the learner finishes the feedback of talk 2, 3 or 4, then every 3rd talk after that (7, 10, 13 …). It never appears after talk 1 (the first talk ends with the drills offer, then the reminder time).

- **Five faces in one radio group:** Bad, Not great, Okay, Good, Great. Each is a Material "sentiment" icon with its word under it, so it never relies on the face alone (AX-5). One tap answers and is saved at once.
- **After a tap:** an optional note, "Want to tell us why?", up to 300 characters, with **Send** (saves the note) or **Not now**. A typed note instead of the PRD's voice comment: a voice note would need recording consent and storage for little gain (decision 2026-11-13).
- **Not now,** or closing the sheet, skips it. The next ask is at the next rating talk; it never asks twice for one talk.
- **On desktop** the same content is a centred dialog.
- **The founder sees the results** in the admin portal: the average score, the share of 4–5 ratings in the last 30 days (the PRD goal is ≥ 70%), and the latest notes.
