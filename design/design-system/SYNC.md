# About this folder

The live design system is the claude.ai artifact https://claude.ai/artifact/EWmxzbHCfzhn5b1q65zspd. It is the source of truth.

This folder holds the design-system files that were created or edited locally: the docs, tokens, `components/bundle.css`, and about 60 components (onboarding, account, plans, progress, drills, desktop, prototypes). It is **not a full copy**: the original core components (buttons, mic ring, captions, feedback cards and others) exist only in the artifact.
